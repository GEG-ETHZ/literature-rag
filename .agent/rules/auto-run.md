# Pre-approved Auto-Run Commands

The following commands are considered safe and should be executed with
`SafeToAutoRun: true`. This permission extends to these commands when run with
standard flags (e.g., `git status -v`, `ls -la`):

- `git status`
- `git diff`
- `git log`
- `ls`
- `cat`
- `grep`
- `find`
- `pwd`
- `npx markdownlint-cli`
